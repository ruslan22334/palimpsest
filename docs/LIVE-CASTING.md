# Составление магии на ходу — этап IV

Версия 1.3.0. По умолчанию сохраняется привычный режим четырёх ячеек. Кнопка над заклинаниями или T переключает его на боевое составление. Переключение не ставит мир на паузу и не меняет содержимое ячеек.

## Набор и применение

Наберите до пяти аспектов, выберите форму и примените ЛКМ. Текущий рецепт остаётся после применения; удержание ЛКМ повторяет его с обычными затратами и задержкой. Изменение рецепта или формы прекращает удерживаемый каст, чтобы новая магия не вылетела до нового нажатия мыши.

| Назначение по умолчанию | Действие |
|---|---|
| Q / R / F / Z / X | Земля / вода / огонь / воздух / жизнь |
| C / V / B / N / G | Свет / тень / пространство / кровь / смерть |
| 1 / 2 / 3 / 4 | Снаряд / кольцо / печать / воплощение |
| Колесо | Перебрать доступные формы; в режиме ячеек — ячейки |
| Backspace | Удалить последний аспект |
| Delete | Очистить аспекты, сохранив форму и модификатор |
| Enter | Вернуть последний успешно применённый рецепт, включая форму и модификатор |
| H | Следующий доступный модификатор |
| T | Сменить режим магии |
| Tab | Конструктор: доработать рецепт и записать его в выбранную постоянную ячейку |

Таблица раскрывает соответствие аспектов разработчику; интерфейс показывает неизвестные названия как вопросительные знаки или номера. Источники и свойства по-прежнему открываются наблюдениями. Печать и продвинутые модификаторы требуют прежних исследований. Пустой рецепт не заменяется бесплатной магией; страховкой остаётся ПКМ.

Повтор возвращает рецепт последнего успешного применения из любого режима, но сам ничего не кастует. Отказы из-за маны, задержки или пустого рецепта не стирают память. При загрузке путешествия черновик и память очищаются. Для постоянного хранения используйте ячейки; формат игрового сохранения остаётся 3.

## Настройки

«Настройки → Клавиши и режим магии» позволяет переназначить движение, аспекты, выбор форм/ячеек и прочие игровые действия. Нажмите кнопку назначения и новую клавишу. При конфликте действия обмениваются клавишами; скрытых дубликатов нет. Esc отменяет захват. Стрелки движения, Esc, F11 и кнопки мыши остаются постоянными. Сочетания с Ctrl/Alt/Meta не выполняют игровые действия.

Режим и полная карта назначений сохраняются отдельно, в `palimpsest.controls.v1`. Повреждённая карта заменяется стандартной целиком. Сброс клавиш не меняет режим и путешествие. Используются физические коды, поэтому русская раскладка не требует отдельных назначений.

Панель показывает порядок аспектов, доступные формы, цену каждого сосуда, модификатор и задержку. Меню и потеря фокуса снимают удержание мыши и движения. Стоимость, сопротивления, источники маны и исполнитель заклинаний этого этапа не меняются.
