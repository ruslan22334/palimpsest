# Палимпсест — Живая магия

Совместная разработка: [CONTRIBUTING.md](CONTRIBUTING.md). Стабильная ветка — `main`, интеграционная — `develop`; новые задачи выполняются в отдельных ветках через pull request.

Одиночная приключенческая игра о магии, которую нужно получать из мира. Полный игровой цикл: исследование → сбор разных видов маны → конструирование заклинаний → восстановление пяти печатей → бой с Переписчиком → завершение истории и свободная игра.

## Запуск

**Windows:** запустите `Palimpsest.exe` из готовой папки игры. В проекте она находится в `dist/Palimpsest-win32-x64`; также можно открыть `PLAY.cmd` из корня проекта. Сначала распакуйте ZIP, если используете архив. Сохраняйте всю папку рядом с EXE: библиотеки и ресурсы обязательны. Node.js, редактор и подключение к интернету игроку не нужны.

**Без настольной сборки:** откройте `index.html` в современном настольном браузере. Либо выполните `npm run dev` и откройте http://127.0.0.1:4173. Сохранения браузера и настольной версии раздельные.

**Из исходников:** Node.js 22+ → `npm ci` → `npm start`. `npm test` запускает проверки, `npm run build` создаёт папку Windows x64 в `dist`. Сборка использует Electron и @electron/packager. Упаковка может потребовать интернет для загрузки официального Electron.

## Первые минуты

1. Выберите «Равновесие» или более мягкое «Созерцание».
2. Постойте на почве — пополнится земля. Пройдитесь — пополнится воздух.
3. Вода находится справа от обсерватории, огонь — справа внизу, кристалл света — слева внизу, пространственный разлом — снизу справа. Деревья дают жизнь. Стрелка ↑ показывает активный сбор.
4. Tab открывает конструктор. Выберите форму, стихию и модификатор; запишите заклинание в одну из четырёх ячеек. Конструктор останавливает время.
5. Идите к «Корням памяти» на запад. Запасите 25 земли и 15 жизни. Нажмите E у печати, победите стражей и нажмите E ещё раз. Выберите реликвию.
6. Осколки врагов и печатей тратятся на исследования в обсерватории. После всех пяти печатей вернитесь к Первому разлому севернее лагеря.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | Двигаться |
| ЛКМ / удерживать | Применить выбранное заклинание |
| ПКМ | Бесплатная слабая искра: страховка при пустых сосудах |
| 1–4 / колесо | Выбрать ячейку |
| Пробел | Рывок за ману воздуха; без движения — в сторону курсора |
| E | Взаимодействовать, отдохнуть, пробудить печать |
| Tab | Конструктор |
| J | Дневник, источники маны и рецепты |
| M | Карта |
| Esc | Пауза / закрыть окно |
| F11 | Полный экран |

Работает русская раскладка: используются физические коды клавиш.

## Магия

Восемь независимых сосудов по 60 единиц (80 с реликвией). Нет общего пассивного восстановления.

| Мана | Как получить |
|---|---|
| Земля | Стоять на почве, лугу, песке или камне |
| Вода | Находиться у воды |
| Огонь | Находиться у огня или лавы; сам опасный тайл наносит урон |
| Воздух | Двигаться |
| Жизнь | Находиться у живых деревьев |
| Свет | Находиться у золотых кристаллов или восстановленных печатей |
| Тень | Стоять на руинах или находиться у разлома |
| Пространство | Находиться у разлома или обсидиана |

Четыре формы × восемь стихий × шесть модификаторов = **192 комбинации**. Стоимость — набор отдельных валют, а не одна общая полоска. Модификаторы открываются исследованиями за 8, 16 и 24 осколка.

Примеры: вода охлаждает лаву до обсидиана; жизнь выращивает рощи на почве; огонь поджигает рощу; земля поднимает сушу из воды и ломает скалы; тень превращает кристаллы в разломы; свет очищает разломы в кристаллы. Воплощение жизни лечит, земли защищает, воздуха ускоряет, пространства телепортирует. Стражи разных типов требуют разных дистанций боя. Защита Переписчика меняется каждые 10 секунд.

## Сохранение и поражение

Один слот автосохранения, каждые 12 секунд активной игры, при паузе и важных событиях. Предыдущая корректная запись служит резервной копией. После гибели сохраняются исследования, печати и реликвии; теряется 20% неистраченных осколков. Точка возвращения обновляется отдыхом у обсерватории или восстановленной печати.

Настольное сохранение находится в профиле Electron `Palimpsest` внутри `%APPDATA%` (Chromium Local Storage). Не очищайте профиль, если хотите сохранить историю. Новая история заменяет текущий слот. Версия сохранения: 1.

## Состав проекта

- `core.js` — данные, мир, источники маны, рецепты и проверка сохранений.
- `simulation.js` — движение, столкновения, магия, враги, прогресс и финал; работает без браузера.
- `renderer.js` — оригинальная процедурная 2D-графика Canvas.
- `game.js` — интерфейс, ввод, сохранения, синтез звука и музыка Web Audio.
- `main.cjs` — изолированная настольная оболочка Electron.
- `tests/` — автоматические проверки механики и боёв.
- `docs/QA.md` — что именно проверялось и границы проверки.
- `docs/RELEASE.md` — состояние сборки и подготовка к публичному выпуску.

## Объём версии

Русский язык, клавиатура и мышь, три режима сложности, один процедурно варьируемый мир из пяти биомов, пять печатей, шесть обычных типов врагов, финальный босс, пять постоянных реликвий, три исследования, сюжетное завершение. Графика и звук создаются кодом; сторонние изображения, музыка и шрифты не загружаются.

Это законченная небольшая играбельная версия, а не обещание сертификации Steam или проверенного коммерческого качества. Публикация в Steam не выполнялась. Ограничения и оставшиеся проверки перечислены в `docs/RELEASE.md`.
