# Правила работы с проектом

- Новую задачу выполняй в отдельной ветке `feature/...`, `fix/...` или `docs/...` от актуальной `develop`. Не вноси рабочие изменения непосредственно в `main` или `develop`.
- Не переключай ветку поверх чужих незакоммиченных изменений. Используй отдельный Git worktree, если текущая рабочая копия занята.
- Направляй обычные pull request в `develop`; `main` предназначена для проверенных выпусков.
- Не выполняй force-push и не переписывай общую историю без прямого указания владельца.
- Проверяй изменения командой `npm test`. Для интерфейса проверяй реальные действия пользователя и отображение при 1280×720.
- Сохраняй основной принцип: каждый вид маны добывается при собственных условиях, а не через общее пассивное восстановление.
- Не коммить сборки, ZIP, зависимости, профили браузера, сохранения и секреты.
- Не меняй лицензию, видимость репозитория и права участников без указания владельца.

Подробный процесс: CONTRIBUTING.md.
